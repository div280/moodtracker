# moodtracker
Developed a Python-based website to track user moods and provide AI-driven suggestions for improvement. 

Overview:
The Mood Tracker Website is a Python-based web application designed to help users track their moods over time. It provides AI-driven suggestions, fun elements like emojis, and visual mood analytics to enhance user experience.

Features:
Mood Logging: Users can input their mood and optionally add a reason.
Daily & Overall Reports: View mood trends for the day or overall history.
Graphical Analysis: Generates mood distribution graphs using Matplotlib.
Streak Tracking: Calculates the user's current and longest streak of mood entries.
Motivational Thoughts & Fun Facts: AI-driven insights to boost user morale.
Interactive UI: Built with Streamlit for a user-friendly experience.

Technologies Used:
Python (Core logic)
SQLite (Database for storing mood logs)
Streamlit (Frontend framework)
Matplotlib & Pandas (Data visualization & analysis)
